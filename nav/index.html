Daily Brief / Issue 0007

五项信号：比较式接口与失败预警

覆盖窗口：2026.09.06 – 09.14
官方口径与作者自报已分别标注
01
高

把 VLM 从下判断改成做比较

C²Nav 换掉零样本 VLN-CE 的模型-机器人接口：不再向 VLM 要航点、像素、朝向、进度值这类基数输出或不可逆的到达决定，而是让它在控制器构造好的候选之间比较，几何、阈值、动作幅度与执行全留在物理侧。

展开全文

免训练三件套：Seeing 在物理上已核验的候选视角间做序数式 Gaze Election；Remembering 维护紧凑路线草图并比较相邻指令段假设；Arriving 用犹豫阶梯、回看比较与可撤销的走回来保证停得住。

OpenNav R2R-CE 100 协议上配 Qwen3-VL-8B-Instruct 得 OSR 41.0% / SR 31.0% / SPL 16.7%，同一接口换 GPT-5.5 得 54.0% / 44.0% / 29.0%。只把比较式答案形式换回基数或绝对式提问，空间、转移、终止三处的 SR 分别掉到 12.0%、28.0%、21.0%——受限决策接口与更强 VLM 推理是互补而非可互换。

02
高

免训练导航收进一套工具协议

HarnessVLN 用 Agent Harness 把感知、检索、接地、导航、恢复与终止统一到一个工具接口下：Harness 拿空间证据、几何可行性与子目标一致性校验规划器提案，并把结构化工具反馈回灌进后续决策。

展开全文

分层事件记忆跟踪任务进度与执行历史，持久化时空图保留可复用的空间证据与失败标注以供核验和恢复；导航执行器可替换，同一套 Harness 协议因此同时支持指令跟随与物体目标导航。

作者自报 R2R、RxR、HM3D-v2、HM3D-OVON 上成功率 60.8% / 53.9% / 76.0% / 59.3%，称超过此前免训练 SOTA，并在人形机器人上做了真实环境部署。均为自报口径，无官方榜单可核。

03
中高

复合扰动推不出来

LIBERO-CTRL 把每个初始状态在单轴条件与匹配的同时扰动条件间配对，暴露出汇总成功率分辨不了的两种反向变化：涌现失败（各单轴都成、同时扰动却败）与补偿成功（有单轴失败、同时扰动反而成）。

展开全文

两者方向相反会互相抵消，于是复合成功率看起来与单轴测量一致，个体结果却已大不相同。即便两类转移率之差在统计上与零无法区分，仍有多达 29.0% 的匹配初始状态改变了结果；六个策略、三档强度下最受影响的条件达 34.5%。

结论直接可用：复合鲁棒性无法只靠单轴汇总成功率刻画，必须做逐实例配对评测。这与 0006 期快慢 agent 的配对实验是同一种方法论。

04
中高

失败信号已经在世界模型里

FARM 的问题很干脆：冻结的预训练机器人世界模型，其内部预测状态里是不是已经直接可解码出失败信息？答案是可以——只在冻结的 VLA-JEPA 预测状态上训一个 33,985 参数的监督读出头，就能给出逐步失败分与因果轨迹风险。

展开全文

七个源任务的五折 out-of-fold 评测达到 85.68 / 88.59 的汇总 AUROC/AUPRC，在 10 任务基准上于 15 个匹配基线中取得最佳 Seen 表现；冻结状态就绪后仅增加 0.2256 ms 平均 CUDA 延迟。

在 PIPER X、SO-101 与 Franka 上的四个真机群体里，用固定读出头迁移与只调读出头两种方式测试部署偏移，全程不更新预测主干。含义是运行时监控未必需要额外训练专用组件。

05
中高

推得快了，闭环行为就变了

同一个 SmolVLA 只换部署后端，闭环行为就变了：PyTorch+AMP 在 LIBERO Spatial 上成功率 70.0%、p99 延迟 1181 ms；两个 ONNX 变体把 p99 压到 601 与 532 ms，Spatial 却掉到 41.0% 与 40.0%。

展开全文

Object 一路维持在 88.0%~89.0%，掉的只有 Spatial。图审计发现那两个所谓 FP16/INT8 产物其实是逐字节相同的 FP32 图，被标为 INT8 的那一行并非算子级量化——『量化即提速』的说法要先做产物核验再谈收益。

静态语言宽度消融（16/24/32 token）给出 Spatial 成功率 41.0%、75.0%、71.0%：宽度 24 的 ONNX 以约一半延迟拿到与 PyTorch+AMP 基线相当的成功率（Wilson 区间重叠，两比例卡方 p=0.53）。作者主张部署评测应同时报告延迟、产物审计、接口约束与闭环成功率。
